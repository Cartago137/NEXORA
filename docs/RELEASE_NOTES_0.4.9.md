# NEXORA 0.4.9 — Edge-to-edge touch editor

- Hide the global NEXORA brand header, mascot and tagline while the touch-layout editor is open.
- Keep bottom and side navigation hidden during editing.
- Remove the editor's outer padding, rounded frame and border so the editing surface fills the full app viewport.
- Preserve the gameplay-like control arrangement, approved sprites, drag/pinch behavior, automatic preferences persistence and separate opacity setting.
