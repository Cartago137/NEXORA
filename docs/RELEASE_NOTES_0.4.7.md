# NEXORA 0.4.7 — Gameplay-style control customization

## Changes
- Reworked the touch editor into a game-like preview with controls grouped as in portrait and landscape gameplay.
- Kept independent drag placement and pinch resizing for D-pad, A, B, L, R, MENU, SELECT and START.
- Moved overall opacity to Settings > Controls, separate from the button placement workspace.
- Preserved the approved control atlas and isolated touch preferences.

## Validation
- Android CI build and regression tests: pending.
- Motorola G54 physical validation in portrait and landscape: pending.

## Data safety
- This update changes touch-control UI/preferences only. It does not delete or rewrite ROMs, battery saves or Save States.
